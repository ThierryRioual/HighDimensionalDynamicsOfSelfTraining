# Repository organization

The repository keeps the manuscript and the numerical implementation together,
so one Git commit identifies both. `src/` remains the existing importable package;
the current API is still `from src.config import ...`. No numerical algorithm,
parameter configuration, loss normalization, or random stream was changed by
the folder reorganization.

| Directory | Role |
| --- | --- |
| `src/` | Reusable numerical implementation. |
| `experiments/` | Two maintained notebook entry points and their shared runner. |
| `scripts/` | Standalone commands, including convention verification. |
| `tests/` | Automated tests and immutable regression fixtures. |
| `manuscript/` | LaTeX sources, bibliography, and required figure PDFs. |
| `docs/` | Current implementation documentation. |
| `docs/audits/` | Historical audits and dated revision records. |
| `outputs/` | Generated results, diagnostic reports, and figure previews. |
| `archive/` | Historical export inventory and locally preserved originals. |

## Previous paths

| Previous path | Current path |
| --- | --- |
| `figures/` | `experiments/` |
| `from figures.experiments import ...` | `from experiments.experiments import ...` |
| `latex/High_Dimensional_Dynamics_of_Self_Training/` | `manuscript/` |
| Manuscript figure PDFs beside `main.tex` | `manuscript/figures/` |
| `latex/.../AUDIT-Fable.md` | `docs/audits/AUDIT-Fable.md` |
| Dated audit and revision reports under `docs/` | `docs/audits/` |
| `tests/mean_field_convention_report.py` | `scripts/check_mean_field_conventions.py` |
| Existing `pdfs/` files | `archive/legacy_exports/`, preserving filenames |
| New PNG plot exports | `outputs/figures/` |
| New manuscript vector exports | `manuscript/figures/` |
| Local LaTeX build products | `manuscript/build/` |

The detailed move inventory, including original checksums and sizes, is
[`archive/inventory.json`](../archive/inventory.json). Historical reports retain
their original paths and line numbers as provenance. Current documentation and
maintained programs use the new paths.

## Naming and version control

Use short lowercase folder names and `snake_case` for Python modules and
notebooks. Existing descriptive LaTeX names are retained. Dates in historical
records use `YYYY-MM-DD`. Figure names describe the experiment rather than its
current paper number.

Version the implementation, tests, notebook configurations, manuscript sources,
and the manuscript's two required PDF figures. Generated previews, numerical
outputs, local historical exports, and compilation products are ignored. The
required manuscript PDFs are explicit exceptions to the general PDF ignore rule.
The retained fixture files remain versioned and are not regenerated by the
standalone verification command.

For any new stored simulation, record its configuration, seeds, source commit,
and relevant environment information beside its outputs. Existing historical
metadata and results are retained as captured; missing provenance is not inferred.

## Manuscript and Overleaf

From `manuscript/`, run:

```sh
latexmk -pdf -outdir=build -interaction=nonstopmode -halt-on-error main.tex
```

Upload the manuscript sources and the `figures/` subdirectory to Overleaf, with
`main.tex` as the main document. `build/` is local and should not be uploaded.
Reconcile independent Overleaf edits before replacing files. This reorganization
does not configure or change any remote Overleaf project.

## Scope

This is a folder and reference migration. A later packaging change could introduce
`src/self_training/` and `pyproject.toml`; it is separate from this migration and
would change the public imports. License adoption remains an author decision.
